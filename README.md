# Multiple Disease Prediction App

Project Highlight:
Deployed a Streamlit-based ML app predicting Diabetes, Heart Disease,\& Parkinson’s using SVM and Random Forest, achieving up to 95.7\% F1-score, with integrated model interpretability and cross-validation for robust evaluation.

This repository contains a [Streamlit](https://streamlit.io) web application that predicts the likelihood of
three different diseases using trained machine learning models.
The app allows a user to enter clinical parameters and returns a simple diagnosis
for each of the following problems:

- **Diabetes** – predicts whether a patient is diabetic.
- **Heart Disease** – identifies if a patient suffers from heart disease.
- **Parkinson's Disease** – determines the presence of Parkinson's from voice measurements.

The goal of the project is to demonstrate how machine learning models can be
served with a user‑friendly interface and how model performance can be analyzed.

## Repository Layout

| File | Description |
|------|-------------|
| `diabetes_model.py` | Python script to train an SVM model with `class_weight='balanced'` on a diabetes dataset, and save the model and feature importance (coefficients) data. |
| `heart_disease_model.py` | Python script to train a Random Forest Classifier model for heart disease, and save the model and feature importance data. |
| `parkinsons_model.py` | Python script to train a Random Forest Classifier model for Parkinson's detection, and save the model and feature importance data. |
| `Multi_DiseasePrediction_Streamlit.py` | Streamlit application loading the above models and displaying feature importances. |
| `requirements.txt` | Lists all Python dependencies required for the project. |
| `Project 2 Diabetes Data.csv` | Dataset for Diabetes Prediction. |
| `Project 9 Heart Disease Data.csv` | Dataset for Heart Disease Prediction. |
| `Project 14 Parkinsons Disease Data.csv` | Dataset for Parkinson's Disease Prediction. |

Trained model files (`*.sav`) and performance data (`*.pkl`) are generated by running the respective model scripts and are expected to live next to the application script. They are loaded using `pickle` when the app starts.

## Running the App

1.  **Create and Activate Virtual Environment (Recommended):**
    ```bash
    python3 -m venv dis-env
    source dis-env/bin/activate  # On macOS/Linux
    # For Windows, use dis-env\Scripts\activate.bat (Command Prompt) or dis-env\Scripts\Activate.ps1 (PowerShell)
    ```

2.  **Install Dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

3.  **Train Models and Generate Data Files:**
    Run each model script to train the models and generate the `.sav` and `.pkl` files (containing feature importances and test data/predictions).
    ```bash
    python3 diabetes_model.py
    python3 parkinsons_model.py
    python3 heart_disease_model.py
    ```

4.  **Launch the Streamlit app:**
    ```bash
    streamlit run Multi_DiseasePrediction_Streamlit.py
    ```

A sidebar will let you choose between diabetes, heart disease or Parkinson's prediction. Input the requested clinical values. The application will display the corresponding diagnosis and a feature importance plot for the selected model.

## Model Selection and Performance

-   The **Diabetes** prediction model now utilizes a **Support Vector Machine (SVM) with `class_weight='balanced'`**. For linear SVMs, feature importance is derived from the absolute values of the model's coefficients, indicating the influence of each feature on the decision boundary.
-   The **Heart Disease** and **Parkinson's Disease** models utilize a **RandomForestClassifier**. This ensemble method often provides a good balance between accuracy and interpretability, and directly supports feature importance calculation.

Hyperparameter tuning (`max_depth=10`, `min_samples_leaf=5` for Random Forest) has been applied to mitigate overfitting, and the models now output True Positives, True Negatives, False Positives, and False Negatives, along with F1-score for test data, to provide a more comprehensive evaluation.

The Streamlit application now visualizes these **feature importance scores**, allowing users to understand which input parameters are most influential in each model's prediction.

For a production‑ready medical tool, further extensive evaluation, cross‑validation, and potentially more complex algorithms trained on larger and more representative data might be considered. However, these models provide a solid foundation for demonstration and analysis.
